# 主页、做题页与转场性能优化

基线：`94f6be7`，2026-10-18。没有启动、重启或调整开发服务器。

## 改动

- 转场以用户指定的正常版本 `8c247da` 为基准：恢复数值 `x/scale` 驱动的横向滑动、轻缩放与模糊，保留 60px 位移、0.97 缩放、0.45 秒时长和原缓动。主页文字和题目入场也恢复数值位移，让 Motion 持续拥有变换值；动画结束只清理滤镜，不手动重置 `transform`。
- 路由与方向一起更新；重复导航通知复用原状态，重复点击不新增相同历史项；前进/后退重新计算方向。退出页设为 `inert`，个人页内部切换标签保持同一个页面实例。
- 星尘闪烁改用原生透明度动画，保留正弦周期、每颗粒子的相位和熄灭区间。线性近似与连续正弦的透明度差小于 0.001；不支持 WAAPI 时沿用原算法。
- 光学场缓存已写入的变换、可见性和星尘样式；复用位置、漂移等逐帧对象；缓存视口尺寸与深度系数；寻找最近符号时只对最终距离开平方。
- 保留原来的模糊/透明度更新阈值，保持 60/120 Hz 等刷新率下逐帧运行。标签页隐藏时取消 RAF，恢复时只启动一个循环；卸载时取消星尘动画。
- 静态模糊光球放进移动容器，便于复用栅格结果。只给实际移动的光球保留合成提示，移除不移动的符号外壳上的提示。渐变、半径、尺寸、位置和动画参数不变。
- 提示语轮播只更新自身；选题时复用背景 React 子树，保存答案后才更新画像背景；只有显示个人空间时才解析该页需要的完整历史记录。

## 可复现对比

```sh
npm run benchmark:optical -- 94f6be7
npm run test:optical
npm run lint
npm run build
npm test
```

基准在确定性的 DOM/RAF 测试环境中运行真实 hook 源码，分别驱动修改前后版本。每个场景运行 600 帧，包含点按对焦、宽窄屏切换；指针和陀螺仪场景持续提供输入，做题场景还更新符号深度。

| 场景 | 模拟刷新率 | 原样式写入次数 | 优化后 | 减少 |
| --- | ---: | ---: | ---: | ---: |
| 主页，以静置为主 | 60 Hz | 27,533 | 7,638 | 72.3% |
| 主页，持续指针输入 | 60 Hz | 29,896 | 16,474 | 44.9% |
| 持续陀螺仪输入 | 120 Hz | 26,661 | 12,913 | 51.6% |
| 做题页，10 个符号与深度更新 | 120 Hz | 22,646 | 3,550 | 84.3% |

每 20 帧检查一次符号坐标、变换、模糊、透明度和对焦框：除星尘透明度外，与基线一致。抽样中的星尘透明度差小于 0.005，包含旧版保留两位小数产生的差异。另以 4,097 个采样点检查正弦近似误差小于 0.001。

回归测试覆盖前后台切换、120 Hz 不限帧、点按锁定及释放、响应式布局、实时符号更新、不支持 WAAPI 的回退、Strict Mode 效果重启，以及监听器和动画释放。转场测试另覆盖三个主页入口及返回方向、重复通知、连续导航、个人页标签实例保持和变换值所有权。

## 验证范围

这些百分比只表示 JS 发起的 DOM 样式写入减少，不能换算成 FPS 提升，也不包含 GPU 绘制成本。原生动画的实际合成加速由浏览器决定，参见 [Motion 性能说明](https://motion.dev/docs/performance)。

按用户要求跳过浏览器证书处理和实机画面验证。布局、毛玻璃、光球合成与切页的最终观感由现有开发服务上的人工检查确认；尚未取得小米 15 Ultra 的 GPU trace 或实测帧率。
